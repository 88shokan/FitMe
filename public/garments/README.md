# Garment images

Save one product photo per catalog entry in `src/lib/catalog.ts`, named by its `id`:

    heavyweight-tee.jpg
    oxford-shirt.jpg
    crew-sweatshirt.jpg
    denim-jacket.jpg
    knit-polo.jpg
    straight-jeans.jpg
    chino-pants.jpg
    shirt-dress.jpg

Flat-lay or plain-background product shots work far better than on-model shots.
Local files (rather than hotlinked store URLs) keep the demo working on bad wifi.
